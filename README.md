# Exam Rank 02 — Practice Solutions

A personal collection of solutions to the **Exam Rank 02** coding exercises, written in C and grouped by difficulty level. Each level's file gathers the small standalone programs for that level, kept together as a study reference.

> These are practice solutions written to learn the patterns behind each exercise, with inline notes. Each exercise is meant to be its own small program: copy a single solution into its own `.c` file to compile and run it.

## Exercises by level

**Level 1** — basic string and I/O handling
`ft_strlen` · `ft_strcpy` · `ft_putstr` · `ft_swap` · `first_word` · `rev_print` · `fizzbuzz` · `rot_13` · `rotone` · `ulstr` · `repeat_alpha` · `search_and_replace`

**Level 2** — strings, sets, and bit manipulation
`ft_atoi` · `ft_strrev` · `ft_strspn` · `ft_strcspn` · `ft_strpbrk` · `last_word` · `alpha_mirror` · `camel_to_snake` · `snake_to_camel` · `wdmatch` · `inter` · `union` · `max` · `do_op` · `print_bits` · `reverse_bits` · `swap_bits` · `ft_is_power_2`

**Level 3** — numbers, recursion, and parsing
`paramsum` · `pgcd` · `lcm` · `add_prime_sum` · `ft_range` · `ft_rrange` · `ft_atoi_base` · `print_hex` · `tab_mult` · `epur_str` · `expand_str` · `hidenp` · `str_capitalizer` · `rstr_capitalizer` · `ft_list_size`

**Level 4** — harder algorithmic exercises
`ft_split` · `ft_itoa` · `fprime` · `flood_fill`

## Running an exercise

Each solution is a complete program with its own `main`. Pick one, put it in a file, and compile:

```bash
cc -Wall -Wextra -Werror solution.c -o solution
./solution <arguments>
```
